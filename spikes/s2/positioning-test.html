Pick — filtering by path

Pick selects a sub-object out of a token stream by matching a filter against the current path, dropping everything else. It is part of the filters family.

Parser — Options

packValues, packKeys, and packStrings emit packed tokens; streamValues emits raw chunks. jsonStreaming enables parsing of multiple top-level JSON values separated by whitespace.

StreamArray — streaming array elements

StreamArray assembles a top-level array one element at a time. It keeps memory bounded because only one element is held at a time, ideal for very large arrays that do not fit in memory.

Stringer

Stringer is the inverse of Parser: it consumes a token stream and produces JSON text, serializing a transformed stream without materializing the whole document.

Verifier

Verifier checks that an incoming stream is well-formed JSON and reports the byte offset, line, and column of the first error, passing data through unchanged on success.
